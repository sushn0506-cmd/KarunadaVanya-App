# Karunada-Vanya App

Karunada-Vanya is an Android application developed using Kotlin and Jetpack Compose to promote wildlife awareness and safety in forest-border regions.

## Features
- Wildlife Information
- Safety Tips
- Wildlife Alerts
- Wildlife Reporting System
- Firebase Realtime Database
- GPS Location Tracking
- AI Assistant
- Google Maps Integration
- Admin Dashboard
- Notification Alerts

## Technologies Used
- Kotlin
- Jetpack Compose
- Firebase
- Google Maps API
- Android Studio
